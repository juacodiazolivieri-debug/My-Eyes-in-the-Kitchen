# My Eyes in the Kitchen 👁️🍳

> An AI-powered everyday agent built with the AWS Strands Agents SDK to act as an audio-visual guide, empowering visually impaired users to cook with complete independence.

---

## 🚀 Overview

**My Eyes in the Kitchen** is designed to eliminate accessibility barriers in the culinary space. For individuals who are blind or have low vision, the kitchen can present safety and navigation challenges. This project introduces a **voice-first, hands-free assistant** that operates seamlessly in the background, transforming device camera input and natural speech into a safe, guided cooking experience.

Built for the **Agents for Humans Hackathon**, this project falls under the **Everyday Agents** track.

---

## ✨ Key Features

* **Real-Time Visual Recognition:** Processes real-time camera feeds to identify ingredients on the counter, check labels, and monitor cooking status.
* **Intelligent Recipe Generator ("What Can I Cook Today?"):** Scans available ingredients and generates tailored recipes on the fly.
* **Voice-First Interaction:** Completely hands-free conversational interface optimized for users with visual impairments (Text-to-Speech & Speech-to-Text).
* **Favorite Recipes Management:** Stores frequent or preferred dishes for instant retrieval through simple voice commands.
* **Step-by-Step Audio Guidance:** Breaks down complex recipes into clear, sequential, and paced audio instructions.

---

## 🛠️ Architecture & Tech Stack

The system relies on a cooperative multi-agent architecture powered by modern cloud and AI tools:


* **Agent Framework:** AWS Strands Agents SDK
* **Cloud & Infrastructure:** AWS (AWS AgentCore)
* **Core Capabilities:** Computer Vision, Generative AI (LLMs), Text-to-Speech (TTS), and Context Memory.
